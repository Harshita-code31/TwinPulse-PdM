# Overview

The PredictivePulse backend exposes REST APIs using FastAPI.

These APIs provide access to historical machine information, AI prediction results, and maintenance alerts. While live telemetry and prediction updates are delivered through MQTT, REST APIs are used for retrieving persistent data stored in the MySQL database.

Swagger documentation is automatically generated and available at:

```
http://localhost:8000/docs
```

---

# Available Endpoints

## Health Check

```
GET /
```

Returns the backend status.

---

## Prediction

```
GET /prediction/{machine_id}
```

Returns:

- Health Score
- Failure Probability
- Remaining Useful Life (RUL)
- Maintenance Recommendation

---

## Machine History

```
GET /history/{machine_id}
```

Returns historical sensor readings for the selected machine.

---

## Alerts

```
GET /alerts
```

Returns all active maintenance alerts generated by the prediction engine.

---

# Flutter Integration

The Flutter application uses these APIs for:

- Historical machine data
- Active maintenance alerts

Live telemetry and AI prediction updates are received directly through MQTT, allowing the application to combine real-time monitoring with historical analysis.

# Summary

The REST APIs provide reliable access to stored industrial data while MQTT handles low-latency communication. This hybrid architecture improves responsiveness without sacrificing historical data access.
