# Database Documentation

## Overview

The Predictive Maintenance backend stores machine information, sensor history, predictions, and maintenance alerts using MySQL.

---

# Entity Relationship

```
Machines

│

├──────────── Sensor Data

├──────────── Predictions

└──────────── Alerts
```

---

# Tables

---

## machines

Stores registered industrial machines.

| Column | Description |
|---------|-------------|
| machine_id | Primary Key |
| machine_name | Machine Name |
| machine_type | Machine Category |
| location | Installation Location |
| installation_date | Installation Date |
| status | Current Machine Status |

---

## sensor_data

Stores all incoming sensor readings.

| Column | Description |
|---------|-------------|
| sensor_id | Primary Key |
| machine_id | Foreign Key |
| timestamp | Reading Time |
| temperature | Machine Temperature |
| rpm | Rotational Speed |
| torque | Torque |
| vibration | Vibration Level |
| current | Current Consumption |
| oil_level | Oil Percentage |
| operating_hours | Total Operating Hours |
| machine_age | Machine Age |
| operating_load | Current Load |
| maintenance_count | Number of Maintenance Cycles |
| fault_type | Current Fault Label |

Relationship

```
sensor_data.machine_id

↓

machines.machine_id
```

---

## predictions

Stores prediction results generated by TensorFlow.

| Column | Description |
|---------|-------------|
| prediction_id | Primary Key |
| machine_id | Foreign Key |
| timestamp | Prediction Time |
| health_score | Predicted Health Score |
| failure_probability | Failure Probability |
| remaining_useful_life | Remaining Useful Life |
| predicted_fault | Predicted Fault |

Relationship

```
predictions.machine_id

↓

machines.machine_id
```

---

## alerts

Stores maintenance alerts generated by the backend.

| Column | Description |
|---------|-------------|
| alert_id | Primary Key |
| machine_id | Foreign Key |
| severity | Alert Severity |
| message | Alert Message |
| created_at | Creation Timestamp |
| is_acknowledged | Alert Status |

Relationship

```
alerts.machine_id

↓

machines.machine_id
```
