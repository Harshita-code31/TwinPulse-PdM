# Database Design

# PredictivePulse

---

## Database

PredictivePulse uses MySQL as its primary relational database.

The database stores:

- Machine Information
- Sensor Telemetry
- AI Prediction Results
- Maintenance Alerts

---

# Tables

## machines

Stores metadata for every simulated industrial machine.

---

## sensor_data

Stores all incoming telemetry published by the Digital Twin Simulator.

Each record includes:

- Temperature
- RPM
- Torque
- Current
- Vibration
- Oil Level
- Operating Hours
- Timestamp

---

## predictions

Stores AI-generated prediction results.

Each prediction contains:

- Health Score
- Failure Probability
- Remaining Useful Life
- Recommendation

Prediction records are accessed through FastAPI and visualized inside the Flutter dashboard.

---

## alerts

Stores active maintenance alerts generated by the prediction engine.

Alerts are retrieved through the REST API and displayed inside the mobile application.

---

# Database Flow

```text
Digital Twin

↓

↓
```

---

# Summary

The database serves as the persistent storage layer for PredictivePulse, enabling historical analysis, AI prediction storage, alert generation, and REST API access.
